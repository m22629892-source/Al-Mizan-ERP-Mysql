# نظام الميزان المحاسبي المتكامل للشركات التجارية في جمهورية مصر العربية
# Al-Mizan Commercial ERP & Accounting System

تم بناء وتطوير النظام كمنظومة ERP ومحاسبة تجارية متكاملة وقابلة للاستخدام الفعلي، تعتمد على قواعد بيانات علائقية ومعاملات ذرية (ACID)، مع محرك قيود مركزي يضمن التوازن المحاسبي، والتوافق مع متطلبات مصلحة الضرائب المصرية (ETA).

---

## 1. البنية التقنية وقاعدة البيانات (Technical Architecture)
- **قاعدة البيانات Relational Database**: محرك SQLite عبر `better-sqlite3` مع تفعيل نمط الكتابة المسبقة `WAL (Write-Ahead Logging)` وتفعيل قيود المفاتيح الأجنبية `PRAGMA foreign_keys = ON;`.
- **الخادم المالي Backend**: Express.js + TypeScript مع طبقات معزولة:
  - `src/server/db.ts`: الاتصال وضبط الـ PRAGMAs.
  - `src/server/schema.sql`: المخطط العلائقي الكامل (23 جدولاً مع الفهارس والقيود الفريدة).
  - `src/server/accounting-engine.ts`: محرك الترحيل المركزي ومحرك القيود العكسية وضبط التسلسل غير المتكرر والتحقق من الفترات المالية وتوازن المدين والدائن.
  - `src/server/api.ts`: واجهات برمجة التطبيقات (REST APIs).
  - `src/server/tests.ts`: مجموعة الـ 12 اختباراً محاسبياً وتنظيمياً حرجاً.
- **الواجهة الأمامية Frontend**: React 19 + TypeScript + Tailwind CSS مع دعم كامل وفوري لـ RTL (العربية) و LTR (الإنجليزية)، وخطوط عربية تنفيذية (Cairo و JetBrains Mono للأرقام المالية).

## 2. دليل تشغيل النظام والتحقق (Setup & Verification Instructions)

- **بيئة التشغيل المعتمدة**:
  - **Node.js**: إصدار `22.x` (LTS، الإصدارات `>= 22.12.0` بما فيها `22.23.3`).
  - **npm**: الإصدار `10.9.x` أو أحدث.
  - **أدوات البناء (اختياري)**: مكتبة `better-sqlite3 v13.0.3` تتضمن حزم ثنائية مسبقة البناء لكافة المنصات (`win32-x64`, `linux-x64`, `darwin-arm64`). في حال تطلب التثبيت تجميعاً محلياً، يلزم توفر `build-essential` و`python3` على لينكس، أو أدوات C++ لـ Visual Studio 2022 (حزمة Desktop development with C++) على ويندوز (مع بيئة `windows-2022` في مسار التكامل المستمر CI لضمان توافقية `node-gyp`).

1. **التثبيت النظيف (Clean Install)**:
   ```bash
   npm ci
   ```
2. **فحص الأنواع وتكامل الشيفرة (Lint & TypeScript)**:
   ```bash
   npm run lint
   ```
3. **بناء الإنتاج (Production Build)**:
   ```bash
   npm run build
   ```
4. **تشغيل كافة الاختبارات المحاسبية والأمنية (Comprehensive Tests)**:
   ```bash
   npm run test:all
   ```
5. **بدء التشغيل في بيئة التطوير**:
   ```bash
   npm run dev
   ```
   يقوم الخادم بإنشاء قاعدة البيانات `almizan.db` تلقائياً، وإنشاء الجداول، وتوليد البيانات التجريبية الشاملة.
6. **الوصول للنظام**:
   افتح المتصفح على: `http://localhost:3000`

### مصفوفة قيود المعاملات:
1. **فاتورة مبيعات آجل**:
   - من حـ/ العملاء التجاريين (حساب الرقابة 1121) [الصافي المستحق]
   - من حـ/ مصلحة الضرائب - خصم وتحصيل 1% (حـ/ 1152) [قيمة الخصم والتحصيل]
   - إلى حـ/ إيرادات المبيعات التجارية (حـ/ 4111) [القيمة الخاضعة]
   - إلى حـ/ مصلحة الضرائب - ضريبة القيمة المضافة مخرجات 14% (حـ/ 2131) [الضريبة]
   - *وقيد المخزون المتزامن*:
     - من حـ/ تكلفة البضاعة المباعة (حـ/ 5111)
     - إلى حـ/ المخزون السلعي (حـ/ 1141)
2. **سند قبض نقدي**:
   - من حـ/ خزينة المركز الرئيسي (حـ/ 1111)
   - إلى حـ/ العملاء التجاريين (حـ/ 1121)
3. **القيد العكسي (Reversal Entry)**:
   - تبديل كامل لأطراف المدين والدائن للقيد الأصلي مع ربطه بالمفتاح `reversed_entry_id` وتوثيق السبب في سجل التدقيق.

## 4. تقرير نتائج الاختبارات الآلية المعتمدة (12 Acceptance Suites)
تم تشغيل الاختبارات الآلية الشاملة وحققت نجاحاً بنسبة **100% (12/12 Passed)**:
1. شراء آجل ثم سداد جزئي ثم مردود مشتريات: **ناجح** (التحقق من توازن المورد والضريبة).
2. بيع آجل ثم تحصيل جزئي ثم مرتجع ورد مبلغ: **ناجح** (عكس الإيراد وضبط تكلفة المبيعات والمخزون).
3. فاتورة بخصومات وضريبة 14% وخصم وتحصيل 1%: **ناجح** (تطابق الحسبة: المدين 10,825 = الدائن 10,825).
4. تحويل مخزون وجرد وتسوية عجز/زيادة: **ناجح** (تطابق كميات المخازن مع الأستاذ العام).
5. قيد يدوي متوازن ومحاولة قيد غير متوازن: **ناجح** (رفض القيد غير المتوازن وتمرير المتوازن).
6. حظر تعديل القيد المرحل والتحقق من آلية القيد العكسي: **ناجح** (عكس القيد مع سلامة القيود الأجنبية).
7. التحكم بالتزامن ومنع صرف كميات غير متوفرة: **ناجح** (معاملات ذرية وقفل فحص الرصيد).
8. منع تكرار التسلسل وأرقام المستندات عند التزامن: **ناجح** (تحديث ذري لتسلسل الفروع والسنوات).
9. تطبيق مصفوفة الصلاحيات وفصل الاختصاصات: **ناجح** (عزل صلاحيات أمين المخزن عن الأرباح والتكلفة).
10. حساب إهلاك الأصول الثابتة وتسجيل مجمع الإهلاك: **ناجح** (حساب دقيق بطريقة القسط الثابت).
11. سجل التدقيق غير القابل للتعديل: **ناجح** (توثيق كامل للعمليات والمستخدمين والبيانات السابقة واللاحقة).
12. تطابق ميزان المراجعة والأستاذ العام: **ناجح** (إجمالي المدين = إجمالي الدائن تماماً).

## 5. النسخ الاحتياطي والاستعادة (Backup & Recovery)
- **النسخ الاحتياطي الساخن (Online Hot Backup)**:
  قاعدة البيانات مخزنة في الملف `almizan.db`. يمكن أخذ نسخة احتياطية آمنة دون إيقاف الخادم باستخدام أمر SQLite الآمن:
  ```bash
  sqlite3 almizan.db ".backup 'almizan_backup_$(date +%Y%m%d).db'"
  ```
- **الاستعادة (Restore)**:
  إيقاف خادم التطبيق، استبدال ملف `almizan.db` بالنسخة الاحتياطية، ثم إعادة تشغيل الخادم.

## 6. قائمة المهام التي تتطلب مراجعة محاسبية وبيانات اعتماد إنتاجية
1. **بيانات اعتماد منظومة الفاتورة الإلكترونية الإنتاجية (ETA Production Credentials)**:
   - يتطلب الحصول على `Client ID` و `Client Secret` من بوابة مصلحة الضرائب المصرية الحقيقية.
   - يتطلب ربط شريحة التوقيع الرقمي الفعلية (Token USB من شركة Egypt Trust أو Misr Sign).
2. **المراجعة المحاسبية القانونية**:
   - مراجعة نسب الخصم والتحصيل للأنشطة غير التجارية (مثلاً 3% للاستشارات والمهن غير التجارية).
   - اعتماد نسب الإهلاك المحاسبية مقابل الإهلاك الضريبي المنصوص عليه بالمادة 25 من قانون الضريبة على الدخل رقم 91 لسنة 2005.
